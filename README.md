# spring-gift-enhancement

0. 기본 코드 준비

1. 엔티티 매핑

`JdbcClient` 기반 코드를 `JPA`로 리팩터링 (도메인 모델 구성 및 객체와 테이블 매핑)

- 엔티티 클래스와 리포지토리 클래스 작성.
    - 아래의 `DDL(Data Definition Language)` 참고

- 객체의 참조와 테이블의 외래 키를 매핑.
  - 객체에서는 참조 사용
  - 테이블에서는 외래 키 사용

- `@DataJpaTest`를 사용하여 학습 테스트

2. 페이지네이션

- 상품과 위시 리스트 페이지네이션 구현
  - Pageable 객체 사용

3. 상품 옵션

상품 정보 옵션 추가

- 상품에는 항상 하나 이상의 옵션이 있어야 함
  - 옵션 이름은 공백을 포함하여 최대 50자까지 입력 가능
  - 특수 문자
    - 가능: ( ), [ ], +, -, &, /, _
    - 그 외 특수 문자 사용 불가
  - 옵션 수량은 최소 1개 이상, 1억 개 미만
- 중복된 옵션은 구매 불가. 동일한 상품 내의 옵션 이름 중복 불가
- 상품 옵션의 수량을 지정된 숫자만큼 빼는 기능 구현
  - 별도의 HTTP API를 만들 필요는 없음
  - 서비스 클래스 또는 엔티티 클래스에서 기능을 구현하고 나중에 사용할 수 있도록 함
- (선택) 관리자 화면에서 옵션을 추가할 수 있음
