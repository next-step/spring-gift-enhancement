# spring-gift-enhancement

# 상품 고도화 과제 - step3 상품 옵션 구현

상품 옵션 도메인을 추가하고, 상품 도메인과 연결합니다.

## 구현 기능

[x] Option 도메인 생성 및 Product와 연관관계 설정
[x] Option API (생성, 수정, 조회) 구현
[x] Option API test 코드 작성

## 참고사항

- Product - Option을 1:N으로 연결했습니다.
- 구현 요구사항에 따라 Option을 생성/수정할 때 각 필드에 유효성 검증 로직을 추가하였습니다.
- Option 기능 테스트를 위한 API와 테스트 코드를 추가했습니다.
- 현재는 일반 사용자도 Option 추가 및 수정이 가능합니다. 이후 관리자용 기능으로 리팩토링하겠습니다.
- 같은 상품 내 중복 옵션 검증은 service 메서드에서 수행합니다. 특정 상품의 옵션 리스트를 불러온 후 하나씩 비교하며 중복이 없는지 검증합니다.
