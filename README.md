## 기능 요구 사항 추가 - step1

- JdbcTemplate 기반 코드를 JPA로 리팩토링
- @DataJpaTest를 사용한 테스트 코드 작성

## 기능 요구 사항 추가 - step2

- 상품 조회에 페이지네이션 구현
- 위시 리스트 조회에 페이지네이션 구현

## 기능 요구 사항 추가 - step3

- 상품에 옵션 기능 추가

  - 옵션 이름
    - 최대 50자까지 허용
    - ( ), [ ], +, -, &, /, _ 이외의 특수 문자 사용 불가능
  - 동일 상품 내에서 옵션 이름 중복 불가능
  - 옵션 수량 : 최소 1개 이상, 1억 개 미만
- 옵션 수량 차감 기능 구현
